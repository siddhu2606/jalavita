Wayfinder — Fisherman's App
Works fully offline once installed
  1. Android (Chrome): Scan the code, then tap Install in the banner — or open the menu (⋮) and choose Add to Home screen.
  2. iPhone (Safari): Scan the code, tap the Share icon, then Add to Home Screen.
  3. Open it from your home screen like any app. It caches everything on first load — after that, turn off data or Wi-Fi and it keeps working: advisory, offline rules engine, catch logging, all of it.
No app store, no APK, nothing to "allow install from unknown sources." This is a real installed app running the same offline-first engine as the Command Deck.
